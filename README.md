# Employee Management System (Java Swing + MySQL)

This desktop application manages employee records using a GUI built with Java Swing and MySQL database.

## 🚀 Setup Instructions

1. Install MySQL and create a database named `java`.
2. Import the database file from `/database/java.sql`.
3. Update database credentials in `pratice.java` if necessary.
4. Add the MySQL Connector JAR (found in `/lib/`) to your classpath.
5. Run the program:
   ```bash
   javac -cp .;lib/mysql-connector-j-8.0.xx.jar pratice.java
   java -cp .;lib/mysql-connector-j-8.0.xx.jar pratice

```sh
java Main.java
```
